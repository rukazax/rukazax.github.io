# Changelog

All notable changes to the site are documented here. Format follows
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), versions use [SemVer](https://semver.org/).

## [1.1.0] — 2026-10-30

### Added
- Страница исследования **ECONA**: `apps/econa.html`, обложка `assets/covers/econa.png`,
  рендеры компоновки `assets/econa/`, карточка на лендинге (теперь четыре проекта).
- `sitemap.xml` и `feed.xml` (RSS) — собираются `build_blog.py` вместе со статьями.
- `404.html` в стиле сайта; автообнаружение RSS на всех страницах.
- `tools/check_links.py` — проверка локальных файлов, якорей и внешних ссылок.
- `tools/make_covers.py` — генерация обложек 1200×630.
- `tools/status.mjs`, `tools/publish.mjs`, `tools/login.mjs`, `.publishignore` — работа с GitHub
  из этой папки (токен общий, вне репозитория).

### Changed
- Английская версия лендинга `en.html` сохранена и доведена: карточки продуктов и статистика
  переведены, добавлена ECONA, переключатель RU/EN в шапке RU-версии, `hreflang`.
- `assets/app.js`: сообщения формы заявки выбираются по `lang` страницы (RU/EN).
- Страницы продуктов и статьи: убран адрес из подвала, ссылки на `x1o.org` заменены
  (публичного сайта у x1o нет), битая ссылка на Cordis исправлена на `cordiverse/cordis`.
- Ссылки на ECONA ведут в `rukazax/econa` — `econa-project` объединён с ним.
- `README.md` — английская версия, `README.ru.md` — русская; структура и сборка описаны по факту
  (`build_blog.py` собирает статьи, список статей, sitemap и RSS; страницы продуктов — статические).
- `tools/publish_site.mjs` — пути выводятся из расположения скрипта, токен берётся из профиля.

### Removed
- Мёртвые ссылки `x1o.org` и `x1o.org/pay` (домен не отвечает), упоминание доната в статье о XIO.

## [1.0.0] — 2026-10-29

### Added
- Единая документация репозитория: `README.md` (EN), `README.ru.md` (RU), `CHANGELOG.md`, `LICENSE`.
- `tools/publish_site.mjs` — публикация в GitHub Pages из репозитория (с автоповтором сборки).
- Описания и темы для всех репозиториев аккаунта в едином формате RU/EN.

### Changed
- Профильная визитка из репозитория `rukazax` перенесена в этот репозиторий и удалена из профиля.
- Страницы продуктов приведены к общему шаблону; описания унифицированы.

### Removed
- Репозиторий `rukazax` очищен от README и переведён в архив.
- `econa-project` объединён с `econa` и переведён в архив.
